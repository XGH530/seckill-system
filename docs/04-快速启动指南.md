## 二、已为你处理好的环境问题

### 问题 1：Maven 中文路径 → 改用直调 java ✅ 已解决

**根因**：官方 `mvn.cmd` 依赖 `JAVA_HOME`，而工具沙箱会污染该变量；
同时 `cygpath` 转换中文路径（`C:\Users\<你的用户名>\...`）时编码错乱，
导致 `-Dmaven.home` 与 classpath 全部失效，报
`找不到或无法加载主类 org.codehaus.plexus.classworlds.launcher.Launcher`。

**处理**：不经过 shell 脚本，直接用 java 调 Maven 的 classworlds launcher，全绝对路径。

```bash
cd "<项目根目录>"

MVN_HOME="C:\Users\<你的用户名>\tools\apache-maven-3.9.9"
java -cp "$MVN_HOME\boot\plexus-classworlds-2.8.0.jar" \
  "-Dclassworlds.conf=$MVN_HOME\bin\m2.conf" \
  "-Dmaven.home=$MVN_HOME" \
  "-Dmaven.multiModuleProjectDirectory=." \
  org.codehaus.plexus.classworlds.launcher.Launcher clean package -DskipTests
```

> ⚠️ `C:\Users\<你的用户名>\tools\mvnbuild.bat` 是在排查过程中创建的，
> **后续实测无效**，请勿使用。上面的命令才是可用的。

**在 IDEA 里更简单**：IDEA 不依赖 shell 脚本，直接设置
`Settings → Build Tools → Maven → Maven home path` 为
`C:\Users\<你的用户名>\tools\apache-maven-3.9.9` 即可。

### 问题 2：Lombok 与 JDK 25 不兼容 ✅ 已解决

**根因**：Spring Boot 3.2.5 默认管理 Lombok 1.18.32，不支持 JDK 23+。
JDK 25 下注解处理器不运行，getter/setter 未生成，报大量「找不到符号 getXxx/setXxx」。

**处理**（`pom.xml`）：
1. 显式指定 `<lombok.version>1.18.40</lombok.version>` 覆盖 Spring Boot 默认版本
2. `maven-compiler-plugin` 中显式声明 `annotationProcessorPaths`

### 问题 3：Sentinel 导致 Tomcat 端口漂移 ✅ 已解决

**根因**：`spring.cloud.sentinel.eager=true`（默认）会在启动早期初始化 Sentinel，
此时主机名无法解析（`Cannot determine local hostname`），初始化失败，
Tomcat 随机挑选端口（实测漂到 51065），日志报 `APPLICATION FAILED TO START`。

**处理**：显式指定端口并关闭 eager 初始化。

```bash
--server.port=8080 --spring.cloud.sentinel.eager=false
```

### 问题 4：Redis 5.0.14 不支持 GETDEL ✅ 已解决

**根因**：`GETDEL` 需要 Redis 6.2+，Windows 原生版最高到 5.0.14。

**处理**：新增 `lua/get_and_delete.lua` 实现原子"取值 + 删除"，
在 `RedisConfig` 中注册 `getAndDeleteScript()` bean，业务代码调用它。

> 💡 延伸：Redis 6.2 引入 GETDEL 就是为了把'取值+删除'变成一条原子命令，
> 在那之前必须用 Lua。这是 Redis 把常见复合操作不断下沉为原语的设计思路。」

### 问题 5（最隐蔽）：Lua 参数被 JSON 序列化器加引号 ✅ 已解决

**症状**：同一个脚本用 `redis-cli --eval` 跑完全正常，
但 `redisTemplate.execute()` 报
`Lua redis() command arguments must be strings or integers`；
修掉后变成 `bad argument #1 to 'floor' (number expected, got nil)`。

**根因**：`redisTemplate.execute(script, keys, args)` 的 args 会经过
`Jackson2JsonRedisSerializer`，字符串被写成 `"86475"`（**带字面双引号**），
于是 `tonumber('"86475"')` → nil。

**处理**：所有 Lua 脚本加 `sanitize()` 剥离成对的外层引号。
完整排查过程见 `docs/06-实战踩坑记录.md` 坑 6。

## 三、启动流程

### 方式 A：命令行（推荐，验证过）

```bash
PROJ="<项目根目录>"

# 1. 启动 Redis（保持窗口开着）
"C:\Users\<你的用户名>\tools\redis\redis-server.exe"

# 2. 打包（如已打包可跳过）
cd "$PROJ"
MVN_HOME="C:\Users\<你的用户名>\tools\apache-maven-3.9.9"
java -cp "$MVN_HOME\boot\plexus-classworlds-2.8.0.jar" \
  "-Dclassworlds.conf=$MVN_HOME\bin\m2.conf" \
  "-Dmaven.home=$MVN_HOME" \
  "-Dmaven.multiModuleProjectDirectory=." \
  org.codehaus.plexus.classworlds.launcher.Launcher clean package -DskipTests

# 3. 启动（demo profile = H2 + 内存队列）
java -jar target/seckill-system-1.0.0.jar \
  --spring.profiles.active=demo \
  --server.port=8080 \
  --spring.cloud.sentinel.eager=false

# 4. 打开接口文档
# http://localhost:8080/doc.html
```

> ⚠️ 打包前若应用正在运行，jar 会被占用导致 `clean` 失败。
> 先停掉 java 进程（`Get-Process java | Stop-Process`）再打包。

### 方式 B：IDEA

1. 打开项目，等待 Maven 导入
2. Maven home path 指到 `C:\Users\<你的用户名>\tools\apache-maven-3.9.9`
3. 运行配置：VM options 加 `-Dfile.encoding=UTF-8`
4. Active profiles 填 `demo`
5. Program arguments 加 `--server.port=8080 --spring.cloud.sentinel.eager=false`
6. 运行 `SeckillApplication`

### 方式 C：接真实 MySQL + RocketMQ

```bash
mysql -uroot -p < src/main/resources/db/schema.sql
mysql -uroot -p seckill < sql/reset.sql      # 重置 + 造压测用户
```
编辑 `application.yml` 填 MySQL 密码，并设 `seckill.mq.rocketmq-enabled=true`，去掉 `--spring.profiles.active=demo`。

## 五、压测怎么跑

项目自带两个纯 Java 压测程序（`pressure-test/`），不依赖 JMeter。

```bash
# 单用户幂等测试：同一用户 200 并发 × 3 轮 = 600 请求
java pressure-test/PressureTest.java http://localhost:8080 1
# 期望：1 成功 / 599 业务拒绝(603) / 0 系统异常

# 多用户超卖测试：200 个新用户抢 99 件库存
java pressure-test/MultiUserPressureTest.java http://localhost:8080 1 200
# 期望：99 成功 / 100 库存不足(602) / 1 重复(603) / 0 系统异常
#       Redis 库存 99 → 0，零超卖
```

> ⚠️ 跑之前先调 `/seckill/warmup` 把库存灌进 Redis；
> 多用户测试前若活动库存已耗尽，需重启应用（demo 模式会重置 H2）。

## 六、常见报错排查

| 报错 | 原因 | 解决 |
|---|---|---|
| `找不到或无法加载主类 ...Launcher` | 用了官方 `mvn`，中文路径被 cygpath 破坏 | 用第二节的直调 java 命令 |
| `找不到符号 getXxx/setXxx` | Lombok 未生效 | 检查 pom 的 `lombok.version` 与 `annotationProcessorPaths` |
| `Unable to connect to Redis` | Redis 没启动 | 启动 `redis-server.exe` |
| `Unknown command 'GETDEL'` | Redis < 6.2 | 已用 `lua/get_and_delete.lua` 兼容，若仍报错检查 `RedisConfig#getAndDeleteScript` |
| `Lua redis() command arguments must be strings or integers` | Lua 参数被 JSON 序列化器加引号 | 检查脚本里的 `sanitize()` 是否被误删 |
| `bad argument #1 to 'floor' (number expected, got nil)` | 同上 | 同上 |
| `APPLICATION FAILED TO START` + 端口是随机数 | Sentinel `eager: true` | 加 `--spring.cloud.sentinel.eager=false --server.port=8080` |
| `Table 't_xxx' doesn't exist` | 没建表 | demo 模式自动建表；MySQL 模式执行 `schema.sql` |
| 秒杀返回"库存未预热" | Redis 里没有库存 key | 调 `/seckill/warmup` |
| 秒杀一直"排队中" | MQ 消费线程没起来 | 看日志是否有「内存MQ 已启用」 |
| `clean` 失败提示文件被占用 | 应用还在运行，jar 被锁 | `Get-Process java \| Stop-Process` 后再打包 |
| 端口 8080 被占用 | 其他程序占用 | 改 `--server.port` |
